# DAX Measure Catalog — Superstore Retail Sales & Forecasting

Home table: `_Measures` (empty table, placeholder column hidden). **34 measures across six
display folders.** Generated from the semantic model TMDL, so this file and the .pbip are
the same source of truth; the prose walkthrough is document 15 §4.2.

Format strings are shown as trailing comments. Measures with no format string are noted.


## 01 Core

```dax
Total Sales = SUM ( FactSales[Sales] )                                  -- $#,##0

Total Profit = SUM ( FactSales[Profit] )                                -- $#,##0

Profit Margin % = DIVIDE ( [Total Profit], [Total Sales] )              -- 0.0%

Total Quantity = SUM ( FactSales[Quantity] )                            -- #,##0

Order Count = DISTINCTCOUNT ( FactSales[Order ID] )                     -- #,##0

Avg Order Value = DIVIDE ( [Total Sales], [Order Count] )               -- $#,##0

Active Customers = DISTINCTCOUNT ( FactSales[CustomerKey] )             -- #,##0

Avg Discount % = AVERAGE ( FactSales[Discount] )                        -- 0.0%
```

## 02 Time Intelligence

```dax
Sales YTD = TOTALYTD ( [Total Sales], DimDate[Date] )                   -- $#,##0

Sales MTD = TOTALMTD ( [Total Sales], DimDate[Date] )                   -- $#,##0

Sales PY =                                                              -- $#,##0
CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( DimDate[Date] ) )

Sales YoY % =                                                           -- +0.0%;-0.0%
VAR PY = [Sales PY]
RETURN
    DIVIDE ( [Total Sales] - PY, PY )

Profit PY =                                                             -- $#,##0
CALCULATE ( [Total Profit], SAMEPERIODLASTYEAR ( DimDate[Date] ) )

Profit YoY % =                                                          -- +0.0%;-0.0%
VAR PY = [Profit PY]
RETURN
    DIVIDE ( [Total Profit] - PY, PY )

Sales 3M Rolling Avg =                                                  -- $#,##0
VAR Period =
    DATESINPERIOD ( DimDate[Date], MAX ( DimDate[Date] ), -3, MONTH )
RETURN
    DIVIDE (
        CALCULATE ( [Total Sales], Period ),
        CALCULATE ( DISTINCTCOUNT ( DimDate[YearMonth] ), Period )
    )
-- denominator counts the months actually present, so partial windows at the series start stay honest

Profit Margin YoY pts =                                                 -- +0.0;-0.0
VAR PriorMargin =
    CALCULATE ( [Profit Margin %], SAMEPERIODLASTYEAR ( DimDate[Date] ) )
RETURN
    IF (
        NOT ISBLANK ( PriorMargin ),
        ( [Profit Margin %] - PriorMargin ) * 100
    )
```

## 03 Quota

Time filtering flows through the physical `SalesQuota[MonthStart]` → `DimDate[Date]` relationship.
Region is bridged virtually with `TREATAS` because Region is not unique in `DimGeography`.

```dax
Quota Amount =                                                          -- $#,##0
CALCULATE (
    SUM ( SalesQuota[QuotaAmount] ),
    TREATAS ( VALUES ( DimGeography[Region] ), SalesQuota[Region] )
)

Quota Attainment % = DIVIDE ( [Total Sales], [Quota Amount] )           -- 0%

Quota Variance = [Total Sales] - [Quota Amount]                         -- +$#,##0;-$#,##0
```
## 04 Accounts

```dax
Last Order Date = CALCULATE ( MAX ( FactSales[Order Date] ) )           -- dd-MMM-yyyy

Days Since Last Order =                                                 -- #,##0
VAR AnchorDate =
    CALCULATE ( MAX ( FactSales[Order Date] ), ALL ( FactSales ) )
VAR LastOrder = [Last Order Date]
RETURN
    IF ( NOT ISBLANK ( LastOrder ), DATEDIFF ( LastOrder, AnchorDate, DAY ) )
-- anchored to the dataset max date (2017-12-30), never TODAY(), because Superstore ends in 2017

Account Status =                                                        -- no format string
SWITCH (
    TRUE (),
    ISBLANK ( [Days Since Last Order] ), BLANK (),
    [Days Since Last Order] >= 180, "Dormant",
    [Days Since Last Order] >= 90, "At Risk",
    "Active"
)

Customer Sales Rank =                                                   -- 0
RANKX ( ALL ( DimCustomer[Customer Name] ), [Total Sales] )

Top 10 Customer Sales =                                                 -- $#,##0
CALCULATE (
    [Total Sales],
    KEEPFILTERS ( TOPN ( 10, ALL ( DimCustomer[Customer Name] ), [Total Sales] ) )
)
-- used on cards and labels; the Page 3 bar chart itself uses a visual-level Top N filter
```

## 05 Forecast & Scenario

The primary forecast is the Analytics-pane forecast on the Page 2 line chart
(ETS, season length 12, 95% CI). These measures add the what-if scenario layer
and a seasonality diagnostic.

> **The `Growth Rate` table is generated by Modeling → New parameter → Numeric range.**
> Do not paste `GENERATESERIES` in as a measure — it returns a table and will error.
> The generated expression is `GENERATESERIES ( 0, 0.305, 0.01 )`; the upper bound is
> padded because float accumulation otherwise drops the final 0.30 step.

```dax
Growth Rate Value =                                                     -- 0%
SELECTEDVALUE ( 'Growth Rate'[Growth Rate], 0.05 )
-- defaults to 5% when nothing is selected

Scenario Sales = [Total Sales] * ( 1 + [Growth Rate Value] )            -- $#,##0

Avg Monthly Sales =                                                     -- $#,##0
AVERAGEX ( VALUES ( DimDate[YearMonth] ), [Total Sales] )

Seasonality Index =                                                     -- 0.00
DIVIDE (
    [Avg Monthly Sales],
    CALCULATE (
        [Avg Monthly Sales],
        ALL ( DimDate[Month Name], DimDate[Month Number] )
    )
)
-- plot by Month Name: >1 = above-average month (Superstore spikes Sep/Nov/Dec)
```

## 06 Card Labels

Text and colour measures for the Page 1 KPI cards. The label measures print the ▲/▼
glyph with `UNICHAR` (9650 = ▲, 9660 = ▼) and stay blank wherever the base measure is
blank. They carry **no format string** — the `FORMAT` calls inside them do the styling.
The colour measures return hex strings and are applied with Format style: Field value.

```dax
Sales YoY % Label =                                                     -- no format string
VAR YoY = [Sales YoY %]
RETURN
    IF (
        ISBLANK ( YoY ),
        BLANK (),
        IF ( YoY >= 0, UNICHAR ( 9650 ), UNICHAR ( 9660 ) )
            & " " & FORMAT ( YoY, "+0.0%;-0.0%" ) & " YoY"
    )
-- card 1.1 reference label

Profit Margin YoY pts Label =                                           -- no format string
VAR d = [Profit Margin YoY pts]
RETURN
    IF (
        ISBLANK ( d ),
        BLANK (),
        IF ( d >= 0, UNICHAR ( 9650 ), UNICHAR ( 9660 ) )
            & " " & FORMAT ( d, "+0.0;-0.0" ) & " pts YoY"
    )
-- card 1.2 reference label

Quota Variance Label =                                                  -- no format string
VAR Amt = [Quota Variance]
RETURN
    IF (
        ISBLANK ( Amt ),
        BLANK (),
        IF ( Amt >= 0, UNICHAR ( 9650 ), UNICHAR ( 9660 ) )
            & " " & FORMAT ( Amt, "+$0.0,K;-$0.0,K" ) & " vs quota"
    )
-- card 1.4 reference label

Sales YoY % Color =                                                     -- no format string
IF (
    ISBLANK ( [Sales YoY %] ),
    BLANK (),
    IF ( [Sales YoY %] >= 0, "#1E7B34", "#C0392B" )
)
-- card 1.1 field-value colour

Profit Margin % Color =                                                 -- no format string
IF (
    ISBLANK ( [Profit YoY %] ),
    BLANK (),
    IF ( [Profit YoY %] >= 0, "#1E7B34", "#C0392B" )
)
-- card 1.2 field-value colour — keyed off Profit YoY %

Quota Attainment % Color =                                              -- no format string
IF (
    ISBLANK ( [Quota Attainment %] ),
    BLANK (),
    IF (
        [Quota Attainment %] >= 1, "#1E7B34",
        IF ( [Quota Attainment %] >= 0.9, "#C8860A", "#C0392B" )
    )
)
-- card 1.4 field-value colour — >= 1 green, >= 0.9 amber, else red
```
