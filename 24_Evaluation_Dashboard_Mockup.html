Triage note 2.5

Accepted, not fixed. The three high-cardinality findings are the composite keys — ProductKey = Product ID | Product Name and GeographyKey = Postal Code | City. Collapsing them to integers would save roughly 40 kB on a 9,994-row model and make every relationship unreadable in the diagram view. The rule is written for hundred-million-row fact tables; it does not apply here. IsAvailableInMdx matters for Excel MDX clients, which this project has none of. Objects should not start with a space fires on the _Measures underscore convention, which is deliberate — it sorts the measure group to the top of the field list. Open items are the two missing geography data categories (a real defect, worth fixing so map visuals bind correctly) and DimProduct[Product ID], retained pending a decision on whether the business key stays exposed.
